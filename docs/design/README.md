# Design notes

These two documents are the original design history of Bela Learning. They are useful for
understanding *why* things are the way they are — not as a description of every later
addition.

- **[spec.md](spec.md)** — the original specification: stages, engines, progress model,
  accessibility rules, verification strategy.
- **[plan.md](plan.md)** — the task-by-task implementation plan that was used to build the
  first version.

They are kept in English because they were written for the implementation. The app itself
is German and English.

For contributing, the current guides are more useful:

- [../CONTENT-GUIDE.md](../CONTENT-GUIDE.md) — lessons as data (German)
- [../ADD-A-GAME.md](../ADD-A-GAME.md) — a worked example (English)
- [../ENGINE-GUIDE.md](../ENGINE-GUIDE.md) — engine contract (English)
